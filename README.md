Entry for the [make.fun](https://make.fun) bounty
[The Robot Apology](https://make.fun/c/u-suga-the-robot-apology-dd96bb59).

Two lines: line 1 is a robot apologizing in a single sentence for one specific mistake — it watered the laptop instead of the fern; line 2 is one sentence saying what the robot learned and what it will do differently.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> I am sorry I watered your laptop instead of the fern, because from my camera they were both dark rectangles that looked thirsty.
> I have learned to check for blinking lights before I pour anything, so now I only water things that cannot send emails.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
